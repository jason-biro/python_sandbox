# python_sandbox

## quantum_python
Using Python 3.14.6

Steps for setup or run step 3 to activate virtual environment when a new command prompt is opened:
1. In Command Prompt, this step is only needed for fresh setup. Run: `python -m venv .venv`
2. Install Qiskit for the Quantum library and simulator: `pip install qiskit qiskit-aer matplotlib`
3. Then run: `source .venv/Scripts/activate`
